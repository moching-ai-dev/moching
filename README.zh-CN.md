## 核心能力

| 领域 | 能力 |
|---|---|
| 🖥️ 屏幕感知 | 看懂屏幕内容，视觉定位任意元素，VLM 驱动 |
| 🖱️ 键鼠操控 | HID 级真实键鼠控制，像人一样操作软件 |
| 🌐 浏览器自动化 | Playwright 驱动，抓取 / 填表 / 批量任务一句话完成 |
| 📄 Office 套件 | Word / Excel / PowerPoint 读写排版全自动 |
| 🎨 AI 媒体 | 图像编辑 · 视频生成 · 语音合成开箱即用 |
| 🧩 MCP 生态 | 一键接入 MCP 市场全部工具 |
